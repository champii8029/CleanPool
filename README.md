# 844CleanPool — Sistema de Cotizaciones

Cotizador web para 844CleanPool: hoja tipo membretada con logo, datos fiscales,
tabla de conceptos con cálculo automático de IVA (16%) en tiempo real, folio
autoincrementable y vista de impresión/PDF optimizada.

## Uso

Abre `index.html` en el navegador (no requiere servidor). O visita la versión
publicada en GitHub Pages una vez activada.

- **+ Agregar concepto**: añade una fila a la tabla.
- **+ Nueva cotización**: incrementa el folio y limpia el formulario.
- **Imprimir / Guardar PDF**: abre el diálogo de impresión con el formato limpio.

Los campos de cliente, vendedor, descripción, cantidad, precio y notas son
editables directamente sobre la hoja.
